In this project, I have used python along with openstreetmaps to find the route between two different places using the DFS, BFS and A* algorithm. This is a simple project to understand how different 
algorithms work to get a solution to the same problem, there are visual representations of the complexity of the algorithms too!!.
The repo has the full iteration of the project so be vary of trying all the code files rather than just one XD.
Also I hope you possess a good computing machine to get the results cause i had to wait for 15 min for the computations to happen and fetch me the results.
